# warehouse-navigator-mobile — приложение навигатора (APK)

Expo / React Native приложение: сканирует QR-якорь склада, ищет товар, показывает
2D-карту со стрелкой «вы здесь», целевой ячейкой и маршрутом. Между якорями позиция
считается по датчикам телефона (PDR). Вся математика — из
[`@smartstack/warehouse-navigator-core`](../core); этот пакет — только UI и датчики.

## Режимы данных
- **Живой (LAN):** на ПК запущен [сервер](../server), телефон в той же сети Wi-Fi.
  В приложении вводится адрес сервера (`http://192.168.x.x:8088`).
- **Офлайн:** в приложение вставляется снимок склада `*.whnav.json` (экспорт из
  ПК-клиента). Навигатор работает без сети.

## Возможности
- Скан QR-якоря (`SSNAV1|warehouseId|xM|yM|headingDeg`) — точная привязка позиции/курса.
- Поиск товара → ближайшая размеченная ячейка → маршрут (стрелка, поворот, расстояние).
- PDR между якорями: шагомер + курс (компас с компенсацией наклона + комплементарный
  фильтр с гироскопом + отсев магнитных аномалий), длина шага по Вайнбергу,
  выталкивание из стеллажей по плану (map-matching).
- Подсказка «пересканируйте якорь» после накопления дрейфа.

> Камера используется только для чтения QR (expo-camera) — без кастомных нативных
> модулей, поэтому APK собирается стандартным Expo-тулчейном. AR-стрелка поверх
> камеры (ARCore/ARKit) — возможное расширение, требует нативного AR-модуля.

## Сборка APK

Требуется Node 18+, Android Studio / SDK (для локальной сборки) либо аккаунт Expo
(для облачной EAS-сборки).

```bash
cd core && npm install && npm run build   # ядро как зависимость (file:../core)
cd ../mobile && npm install

# Dev на подключённом устройстве/эмуляторе:
npx expo run:android

# Релизный APK через EAS (облако):
npm i -g eas-cli && eas login
eas build -p android --profile preview     # вернёт ссылку на .apk

# Либо локально: npx expo prebuild && cd android && ./gradlew assembleRelease
#   APK: android/app/build/outputs/apk/release/app-release.apk
```

Проверка типов: `npm run typecheck`.
