# warehouse-navigator — навигация по складу (мобильный APK + ПК-клиент)

Indoor-навигация «доведи до товара» для склада: телефон показывает, куда идти к
ячейке с нужным товаром. Локализация **без GPS** (в помещении он бесполезен): точный
сброс по **QR-якорям** + относительное счисление между ними (камера/ARCore либо
датчики телефона). Только четыре сущности: **склад, ячейки, товар, навигатор.**

Извлечено из проекта SmartStock. Каждый слой автономен, лицензия MIT.

## Быстрый старт (живой режим по LAN)

```bash
# 1. собрать ядро
cd core && npm install && npm run build && npm test

# 2. поднять LAN-сервер на демо-складе
cd ../server && npm install && PORT=8088 npm start -- ../examples/demo.whnav.json
#   сервер напечатает адреса вида http://192.168.x.x:8088

# 3. собрать и поставить мобильное приложение (APK), ввести в нём адрес сервера
cd ../mobile && npm install && npx expo run:android         # dev
#   релизный APK: eas build -p android  (см. mobile/README.md)
```

Офлайн-режим: в ПК-клиенте «Экспорт снимка» → файл `*.whnav.json` → передать на
телефон → в приложении «Импорт снимка». Навигатор работает без сети.

## Формат QR-якоря

Строка QR: `SSNAV1|<warehouseId>|<xM>|<yM>|<headingDeg>` — позиция «вы здесь» (метры)
и направление взгляда (градусы, 0° = север, по часовой). Парсер и валидация —
`core` (`parseAnchor`). Координаты склада: X вправо (восток), Y вверх (север).

## Точность

GPS в помещении недоступен (стены/металл, погрешность ≫ размер ячейки). Подход:
- **QR-якорь** — абсолютный сброс позиции и курса (точно, дискретно).
- **AR/VIO** (ARCore/ARKit) — относительное движение между якорями (точно, дрейфует).
- **PDR** (датчики) — фолбэк без AR: шагомер + курс. Повышение точности в `core`:
  гиро+магнитометр (комплементарный фильтр), длина шага по Вайнбергу, отсев
  магнитных аномалий у металла, map-matching (не «ходить сквозь стеллажи»).
- **Оптическо-инерциальная фузия** — когда оптика (ARCore VIO) видит ориентиры,
  она непрерывно **выправляет накопленный дрейф PDR** (мягкий трим + жёсткий снап
  при крупном расхождении); при потере трекинга навигация не замирает — ведёт PDR.
- **ZUPT** — пока человек стоит (детектор покоя по дисперсии |a|), оценивается и
  вычитается **смещение нуля гироскопа** → курс не уползает.
- **Калибровка длины шага** — по паре QR-якорей (истинное расстояние vs пройденное
  по PDR) масштаб шага подгоняется под рост/походку конкретного человека.
- **Выправление стрелки по 3D-плану** — если прямая на ячейку упирается в стеллаж/
  стену, направление отклоняется в сторону свободного прохода (далёкие препятствия
  игнорируются) — это геометрия по известному плану, а не сегментация кадра камеры.
