# Установщик SmartStock Мессенджера

Собирает один `Setup.exe` со всем необходимым (Qt-DLL, плагины, libsodium, CRT) —
раздавать сотрудникам без сборки и без установки Qt/MSVC.

## Требования
- Собранный клиент: `cmake --build build --config Release` в `messenger-desktop`.
- Qt 6.5.3 (`windeployqt`), vcpkg с `libsodium`, NSIS (`makensis`).

## Сборка
```powershell
cd packages/messenger-desktop/packaging

# Обычный установщик (сотрудник сам вводит адрес сервера)
./build_installer.ps1

# Со ВШИТЫМ адресом сервера компании (склейка) — поле «Адрес сервера»
# уже заполнено, сотрудник вводит только ключ и пароль
./build_installer.ps1 -ServerUrl https://erp.компания.ru
```
Готовый файл — в `messenger-desktop/установщики/`.

## Как работает склейка
Флаг `-ServerUrl` кладёт в установщик файл `server.txt` рядом с exe. При первом
запуске клиент берёт адрес оттуда (если пользователь ещё не входил). Так под
каждого клиента/компанию собирается персональный установщик за секунды — пересборка
C++ не нужна.

> Приоритет адреса: ранее введённый пользователем → вшитый `server.txt` → `localhost`.
